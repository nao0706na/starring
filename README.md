# STARRING

**教材の主語を、「自分」に。**
自分の問いで学び、仮想学校で出番を見つける。

> AIエージェント アイデアソン by Animoca Brands Japan 出品作品

## 概要

STARRINGは、学習者自身を教材の主役にするAIエージェント型学習サービスです。

学習目標や本人が選んだメモ、過去の回答をもとに、興味に合った教材と問いを提供します。さらに、AIの先生や同級生がいる仮想教室で学んだ知識を自分の言葉で説明し、その結果に応じて次の教材や復習を調整します。

Mindsの記憶・Skill・Circleなどを活用し、まずは英語の学び直しを対象とした2D教室から検証する構想です。

## 解決したい課題

- 最初に届けたいのは、英語を学び直したい18歳以上の人
- 目標はあるのに、毎回「何から始めるか」で止まってしまう
- 目標はある → 入口が重い → だから続かない

## 発想のきっかけ

集合写真を見るとき、人はまず「自分」を探します（デール・カーネギー『人を動かす』1936）。
この「自分への関心」を学びの入口にできないか、と考えました。

## エージェントの流れ

| # | ステップ | 内容 |
|---|---|---|
| 1 | 読みとる | 目標・本人が選んだメモ・前回の回答 |
| 2 | 教材と問いを届ける | 興味に合う短い教材と、説明するための問い |
| 3 | 仮想教室で答える | AIの先生・同級生の前で、自分の言葉で説明 |
| 4 | 次を選ぶ | できたら応用へ、難しければ復習へ |

結果は次回へ引き継ぎ、この流れを毎回くり返します。「何から始めるか」で止まる負担を、エージェントが引き受けます。

## 褒め方と競争の選択

- 反応は「説明の中身」に返す（根拠のない「天才！」ではなく、どこがよかったかを返す）
- 競争も通知も本人が選ぶ：**OFF**（マイペース）／**CO-OP**（協力モード）／**RIVAL**（ライバルと競争）
- 競争はいつでも止められる

## 技術構成（初期版の構想）

| 役割 | 使う機能 |
|---|---|
| 自分を覚えて、次を選ぶ進行役 | Mind（長期記憶をもち、裏側で自律的に動く） |
| 教材 → 出題 → 確認 → 次回をつなぐ流れ | Skill（手順を決めた一連の流れをMindに装着） |
| AIの先生・同級生 | Circle（複数のMindが文脈を共有して協働） |
| STARRINGの教室画面とつなぐ | Minds Connect SDK（本人の同意で外部アプリから会話・スキル装着） |

将来は、ワールドモデル（例：Google DeepMind Genie 4）で教室を「入り込める世界」へ広げることを目指します。
